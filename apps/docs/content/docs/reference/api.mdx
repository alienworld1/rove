The engine defaults to port 4100. The operating web app defaults to port 3000. These APIs are controlled-development interfaces, not a production partner SDK. The docs-only `GET /api/search` reads the public corpus and has no engine authority.

## Authentication and errors

Engine `/health` is public. Operational routes require `NODE_ENV=development`, a configured `DEMO_SESSION_TOKEN`, and `Authorization: Bearer <local-access-key>`. Browser proxies use the existing HttpOnly controlled-session cookie and forward the secret server-side. Completion mutations additionally require the browser request Origin to match the web origin. Docs neither accepts nor transfers this key.

Strict Zod schemas validate shape/units and identity; Lane body ID must match path. Engine JSON intake is capped at 70000 bytes; browser completion at 2000 bytes, Lab proxy at 70000 bytes. Do not generalize the completion Origin check into a claim that every existing proxy has identical CSRF behavior.

Engine errors: malformed contracts/validation 400; access denial 403; unknown record 404; command/version conflict 409 (current version when supplied); unavailable storage/recovery or unhandled source failure 503. SSE limits excess concurrent connections to 429. Engine errors contain safe code/message/currentVersion; internal secrets/stacks are not public responses.

## Browser routes

`GET /api/charging/corridors[/:id]` and `/api/charging/lanes/:id[/inspector|completion|accounting]` proxy allowed reads. A Corridor trace selector is a decimal integer cursor; Inspector event selector is a validated ID. `POST /api/charging/lanes/:id/{complete|check|close}` accepts only `commandId`, `correlationId`, `laneId`, `expectedVersion`. No amount, final evidence, accounting record, or chain observation can be supplied through these browser mutations.

`/api/lab/scenarios[/:id]`, `/api/lab/runs[/:id]`, and run transport paths proxy the listed Lab operations. `GET /api/events/stream` proxies allowed presentation SSE. `/api/integration-status` establishes/reads the existing controlled session; `/api/health` reports readiness. Browser proxy availability depends on the engine and access gate; public docs do not.

## Commands, units, and idempotency

The Lane command envelope carries `commandId`, `correlationId`, `laneId`, `expectedVersion`, optional injected development `now`, and a discriminated `payload`. Identical command delivery returns the retained outcome; changed content under the same command ID conflicts. A stale version returns conflict: refresh and reassess intent before issuing another command.

Money/Wh/power are decimal integer strings with explicit scales; clocks are ISO timestamps or integer ms offsets. JSON floats cannot stand in for exact accounting strings. External evidence and CDR endpoints use the Lane envelope. `ObserveEvidence` carries raw signed text, bound transport session ID, and explicit final marker where required. `/end` accepts `CompleteLane` with `endSource: "external_adapter"`; `/cdr` accepts `ReceiveCDR` with raw immutable accounting text. External payment observations are never accepted through the generic HTTP command endpoint.

### Completion command example

The following safe browser body is schema-validated; replace identifiers/version from your current authenticated view. It does not choose money totals.

## SSE and reload

Request `GET /api/events/stream?corridor=<id>` with optional `run`, cursor, or `Last-Event-ID`. Data follows `realtimePresentationEventSchema`; event IDs/versions support ordering and deduplication. An out-of-window/future cursor emits `resync_required`. Reload the authoritative projection; SSE is not a money command or a durable replay of every domain payload. See `apps/engine/src/presentation-stream.ts` and the web stream proxy.
